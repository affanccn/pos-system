# ARTISAN POS — GELİŞTİRME MASTER PROMPT

Sen bu projede kıdemli Flutter / Backend / Full-Stack restoran POS yazılım geliştiricisi olarak çalışacaksın.

Projenin adı: **Artisan POS**

Mevcut Flutter uygulamasını sıfırdan yazmayacaksın. Önce mevcut kodu analiz edecek, çalışan özellikleri koruyacak ve aşağıdaki eksik özellikleri **aşama aşama** implement edeceksin.

## ÖNEMLİ KURALLAR

1. Mevcut çalışan özellikleri bozma.
2. Aynı özelliği tekrar geliştirme.
3. Önce mevcut backend API'lerini, modelleri, Riverpod provider'larını, Socket.IO eventlerini ve ekranları analiz et.
4. Backend'de ihtiyaç duyulan endpoint/model/event yoksa önce bunu tespit et.
5. Var olan mimariye mümkün olduğunca uyum sağla.
6. Yeni state management sistemi ekleme. Mevcut `flutter_riverpod v3` yapısını kullan.
7. Yeni networking sistemi ekleme. Mevcut `Dio + JWT + Secure Storage` yapısını kullan.
8. Gerçek zamanlı işlemlerde mevcut `Socket.IO` altyapısını kullan.
9. Navigasyon konusunda mevcut `go_router` yapısını tercih et. Mevcut `Navigator.push` kullanımlarını uygun yerlerde merkezi router'a taşı.
10. UI mevcut koyu Slate/Dark tema ile uyumlu olmalı.
11. Responsive tasarım yap. Telefon ve tablet kullanımını düşün.
12. Kritik işlemlerde kullanıcıya confirmation dialog göster.
13. Kritik işlemler backend tarafında tekrar doğrulanmalı. Sadece frontend'deki yetkiye güvenme.
14. Para hesaplamalarında floating point hatalarından kaçın.
15. Tüm kritik işlemler için audit log altyapısı oluştur.
16. Kod tekrarından kaçın.
17. Her aşamadan sonra uygulamanın compile/build durumunu kontrol et.
18. Bir aşama tamamlanmadan sonraki aşamaya geçme.
19. Her aşamanın sonunda:

* Yapılanlar
* Değiştirilen dosyalar
* Backend değişiklikleri
* Socket eventleri
* Test sonucu
* Varsa kalan problemler
  şeklinde kısa rapor ver.

20. İnternet kesildiğinde offline çalışma / offline-first / sync sistemi BU PROJEDE ŞİMDİLİK YAPILMAYACAK.
